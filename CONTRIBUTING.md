# Contribuire a WISP

Grazie per l’interesse. Prima di aprire una modifica:

1. non aggiungere registrazioni, conversazioni o dati personali;
2. non aggiungere modelli, voci, immagini o storie senza una licenza redistribuibile;
3. mantieni la componente conversazionale indipendente dal pannello web;
4. accompagna le modifiche funzionali con test;
5. non dichiarare funzionalità hardware non verificate su un dispositivo reale.

Esegui `python -m pytest` prima di proporre una modifica.
